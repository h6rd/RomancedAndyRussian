# Romanced Andy (0.2.2) – Russian Translation

Russian translation (`ru.json`) for the Stardew Valley mod **Romanced Andy**

> This is **only a translation**

## Links
- Original mod: [Romanced Andy](https://www.nexusmods.com/stardewvalley/mods/35914)
- This translation on Nexus Mods: [Russian Translation](https://www.nexusmods.com/stardewvalley/mods/53488)

## Requirements
- [SMAPI](https://smapi.io/)
- [Stardew Valley Expanded](https://www.nexusmods.com/stardewvalley/mods/3753)
- [Romanced Andy](https://www.nexusmods.com/stardewvalley/mods/35914)

## How to install
1. Install the requirements and the original mod
2. Download this translation
3. Put `ru.json` into `Mods/RomancedAndy/i18n/`
